# Public Sharing And Privacy Notes

This repository is intentionally sanitized for public portfolio use.

## Safe To Include

- Architecture notes.
- High-level system flows.
- Mermaid diagrams.
- Pseudocode-style examples.
- Public-safe metrics.
- General technical decisions and tradeoffs.

## Not Included

- Raw Lua scripts.
- Raw SQL schemas or database exports.
- Server configuration.
- Admin tooling details.
- Player account data.
- Credentials, API keys, or deployment secrets.
- Full private project folders.
- Exploit-sensitive implementation details.

## Sharing Approach

The goal is to show systems thinking, technical communication, and implementation reasoning while keeping live platform internals private.
